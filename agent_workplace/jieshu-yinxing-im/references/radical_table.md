## 备注

合体字的主码为其部首对应的字母（部首码），部首的选取遵循以下规则：（康熙部首+优化分配）

基本原则：

1. 直觉优先
2. 康熙部首验证
3. 优化分配（现代字形，避重，历史）
4. 部首表对应（表外部首处理：变体，代替，简并，跳过）

## 部首表体系术语精解

以下术语在规则文档中已分散出现,此处集中定义,作为推导时的精确词汇表。

1. **部首表**：将一系列部首划分到若干字母中,形成的映射表。见 上方部首表。

2. **部首码**：某个具体部首在部首表中对应的字母。如「金」在 j 行 → 部首码 j。

3. **部首双码**：在部首码的基础上在增加一位，两位精准确定一个部首。主要用在解书拆分中，日常编码不涉及。比如"金"部首双码"jr"。

4. **部首次码**：部首双码的第二位(次位)，在规则文本中通过**部首次表**定义，上方部首表直接展示拼合成部首双码的结果。比如"金"部首次码"r"。部首次码的取码逻辑比较模糊，以韵母映射、字形相似为主，也有纯区分的，不作探讨。

5. **表内部首**：该部首在部首表中存在。如「金」「木」「水」「火」「土」均在表中。不算a，表内部首一共有183个。

6. **表外部首**：该部首不在部首表中。在主码逻辑中需走变体统一 / 非部首字代替 / 简并 / 跳过四条路径处理（见 `rules.md` 3.4 节）。

7. **音托部首**：表内部首,且其初码 = 部首码。如「口」初码 k = 部首码 k → 音托部首。音托部首有135个，占比约74%。这里的“初码”更多地是其作为**部首**时的代称，比如“宀”应视为“宝盖头”因此取“宝”初码b。

8. **别码部首**：表内部首,且其初码 ≠ 部首码。如「车」初码 i ≠ 部首码 c → 别码部首。别码部首有48个，占比约26%。

9. **部首别码**：别码部首的部首码——即某个表内部首的、不等于其初码的那个部首码。如「车」的部首别码 c。

10. **xx部（字）**：借用传统汉字学观念的部首归属说法。如「江」属水部、「删」属刀部。对应康熙部首查字法。

11. **xx行（码）**：某部首码对应的一整行部首。如 u 行包含水、矢、手、食、山、士、豕、身。「江」的主码取 u,因为其部首「水」在 u 行。

## 音托与别码的真正分野（注释视角）

上一节定义的"音托/别码"在简化意义上等同于"部首码 = 初码"或"≠ 初码"（见 `rules.md` 第 305 行）。那个定义是从**结果**反推的：拿到一个部首码后，对照其字源读音的初码，看是否相等。本节解释**该部首码当初是怎么被定出来的**——这才是"音托"和"别码"标签的真正分野。

### 音托部首：选用高频借字（普适日常化）

"音托"= 音被某个字**托**着。意味着部首码的设计**不依赖字源罕读音，而是从一个高频日常字（"代表字"）借来**。

分两种情形：

1. **自身即高频字**：部首字本身是日常高频字，备注不必借字。例如「木」mù、「水」shuǐ、「火」huǒ、「口」kǒu——整字音本身就在日常使用中，部首码 = 整字自身的初码，无需另找代表字。这种情形下，"部首码 = 初码"是**自然成立**的。

2. **设计音托（借字定音）**：部首字本身存在两个或更多读音，**日常中更常用的那个读音即作为"代表字音"被保留**；其余罕读音被"无视"——并非字源罕读，而是"两个音里更普适的那一个"。设计者直接把常用音的初码定为部首码：

这两种情形在 `rules.md` 第 305 行的简化定义里被合并为"部首码 = 初码"——但前者是自然成立，后者是**人为对齐到日常高频字音**（宀/廴/囗/疒 借别的字；丬 从自身多音中选更普适的那一个）。从设计意图看，两者的共同点是：**部首码都对齐到日常高频字音上**。这是"音托"标签的核心价值——**让拆字时遇到的视觉特征（宝盖头/廴字旁/国框）能直接触发一个常用字（宝/建/国），进而给出部首码**。

### 借字定音与位置继承的区分

除了"借字定音"，还有一类很容易混淆的形态——**位置继承型音托**。两者表面相似（都是"用一个音代表另一个字"），但底层机制不同：

- **借字定音**：部首字本身有（一或两个）整字音，**部首码 ≠ 整字音**，借自**另一个完整高频字**。被借的字有完整字形、完整读音，音是真实存在的。
- **位置继承型**：部首字本身**没有独立整字音**（只是另一个字的局部/变体），**跟随所属字所在行的归属**。它借的是"行归属"（位置），不是"音"。

| 类别        | 关键特征                | 备注中的写法              | 例子                             |
| --------- | ------------------- | ------------------- | ------------------------------ |
| **借字定音**  | 部首字有自身读音，但部首码 ≠ 整字音 | "X→Y"、"无视 X 音"      | 宀/廴/囗/疒/丬/卄/屮/尢                |
| **位置继承型** | 部首字无独立整字音，进所在行靠所属字  | "X 字头"、"X 变体"、"同 X" | 𡗗（春字头）、学字头（𰃮）、龶（青字头）、𠘨（几变体） |

**关键区别**：位置继承型虽然也"挂靠"在某个字上，但被挂靠的字是**所属字本身**（春/学/青/几），而不是"另一个完整高频字"。换句话说：

- 借字定音 = "宀 → 借 '宝'（另一个完整字）→ b"
- 位置继承 = "𡗗 → 跟 '春'（所属字）→ i"

**位置继承（比如"𡗗""𠘨"等）不属于借字定音**。它们虽然也是"音托"，但机制是"行归属继承"，不是"音的借用"。

### 别码部首：部首码来自概念性描述或与自身音冲突

"别码"的出现，是当**无法找到一个合适的借字**时——要么是因为没有自然联系、要么是因为借字音和自身音打架。备注栏里通常表现为：

1. **概念性描述**：备注写"顶部"、"坎"、"双耳刀"等**非借字**的概念词，反映部首码并非从某个字派生，而是按字形定位或优化分配。例如「亠」备注"顶部+'点'；tou2"——"顶部"是位置描述，"tou2"才是自身音；「冖」备注"顶部；无视 mi4"——也是位置描述。
2. **自身音被显式标注**：备注里直接写出部首字自身的拼音（如"tou2"、"y 迁移至 i"），暗示部首码**不能通过借字机制获得**，必须依赖概念性分配或显式约定。例如「雨」备注"y 迁移至 i"——明确告诉你部首码 i 是从字源音 y"迁移"过来的特例。
3. **音托机制被覆写**：备注栏同时存在"借字音"和"自身音"且二者冲突。例如「阝」备注"音托自'部'b"——本来想借"部"字定音，但阝本身读 fǔ/yì，借字音（b）与自身音（f/y）不同，且任一音都不常见，**借字机制失效**——所以阝最终仍标"别码"。

### 注释视角的总结

从设计意图看，"音托"和"别码"的分野**不是**"部首码 = 初码"这种字面等式，而是**该部首码的选取是否对齐到了日常高频字音**：

- **音托**：无论借字还是自身，部首码来自某个**日常高频字**的初码，便于拆字时"形→音→码"的条件反射。
- **别码**：部首码来自**概念性描述**或**字源音迁移**，拆字时无法直接借高频字作为桥梁，需要额外记忆。

因此，当查阅 `rules.md` 第 305 行的简化定义时（"部首码 = 初码 → 音托"），应理解为**该定义在两种情形下都成立**——一是部首字本身是高频字（自然成立），二是部首字虽是字源罕读音但已通过借字机制对齐到高频字（设计成立）。**该定义不要求部首字**自身**的字源音与部首码相等**——这是"音托"的设计弹性所在，也是为何 135 个音托部首能在日常拆字中顺畅使用。

## 特殊部首规则说明

在优化分配方法中（`rules.md` 3.3 节），有一条「特定部首规则」，原文档仅记载了"含彳取彳，含廾取廾"两条。实际上在编码实践中积累了大量此类规则，它们分散在部首表 PPT（`help/部首表.pptx`）各页备注中，本质都是同一条优化分配原则：**当特定部件出现时，优先（或次取/跳过）取该部件为部首，而不依赖康熙部首的默认判断。**

以下按部首码字母分组，逐条列出已确认的特定部首规则及其在码表中的验证：

#### 上「西」优先（X 行）

**规则**：「西」（包括变体「襾」「覀」）在上部时，有优先性，取西不取下部件。

**验证**：

| 字   | 编码   | 下部实际部首 | 康熙部首 | 下部部首码 | 实际取 |
| --- | ---- | ------ | ---- | ----- | --- |
| 票   | pc4x | 示      | 示    | s     | 西 x |
| 栗   | li4x | 木      | 木    | m     | 西 x |
| 粟   | su4x | 米      | 米    | m     | 西 x |

三个字的字源上部各不相同（票=甶变体、栗=㮚上部、粟=角/甶简化），隶变后均归于「西」，统一取 x 形成可预测的编码模式。

#### 左「禾」优先（H 行）

**规则**：「禾」有一定优先性，在左右结构中优先取禾。

**验证**：和 he2h、利 li4h。这两个字中均取 h 不取口/刂。

#### 外「行」取彳（T 行）

**规则**：「行」作为汉字外框时优先取，「行」简并至「彳」，不考虑是否是形旁。

**验证**：衡 hg2t。衡字外部为「行」（中间夹一个𩵋），外「行」→ 取彳，部首码 t（别码）。

#### 含「廾」取廾（C 行）

**规则**：首次拆分下半部分为「廾」的字，其部首确认为「廾」，所有「艹」衍生及变体「廾」均适用。

**验证**：奔 bf1c。奔的康熙部首为大（大部），下部可拆出廾 → 取廾 → c。

#### 「廴」优先（J 行）

**规则**：「廴」有一定优先性，无视 yin2 读音。

**验证**：延 yj2j。廴本身是康熙部首之一，但它的优先性体现在与「廴」形近的其他部件竞争时——有廴取廴，不纠结。

#### 「老」优先（L 行，含变体「耂」）

**规则**：「老」及变体「耂」（老字头）有优先性。

**验证**：者 ve3l。者字康熙部首为「老」（耂），取 l。

#### 「青」优先（Q 行，含变体「龶」）

**规则**：「青」及变体「龶」（青字头）有优先性。

**验证**：毒 du2q。毒的康熙部首为毋，但上部含龶 → 取青 q。

#### 「匚」优先（O 行）

**规则**：「匚」有优先性。

**验证**：医 yi1o / yi4o。医的康熙部首为酉（y），但匚包围结构 → 取匚 o（别码）。

#### 「彐」可能次取（I 行）

**规则**：「彐」（包括片假ヨ→yo）有次取倾向，即当更优先的部件不存在或已被占时，取彐。

**验证**：录 lu4iu。录字在第一直觉下难以确定部首，彐作为次取候选，取 i。

#### 「𡗗」次取（I 行）

**规则**：「𡗗」（春字头）有次取倾向。

**验证**：奉 fg4i。奉的康熙部首为大（d）但在现代字形中消失，𡗗为次取 → 取 i。

#### 「辰」次取（F 行）

**规则**：「辰」有次取倾向。注意：「辱」字跳过辰，取部首「寸」（ru3c）。

PPT 备注：「辰」暂无直接例字，这暗示辰在与其他部件竞争时优先级偏低——当字内同时存在其他更优先的部件时，辰让位。

#### 「娄」部仅一字（L 行）

**规则**：优化分配，仅「数」一字以娄为部首。

**验证**：数 uu3l / uu4l。

#### 含「勹」：内不成字则独体，内成字则严格取外（L 行）

**规则**：来自解书拆分的包围结构 l.（bao1）。含「勹」的字，判断内部是否成字——内不成字 → 视为独体字（不拆部首）；内部成字 → 严格取外（勹为部首）。

**验证**：旬 xp2l。旬的内部是「日」，成字 → 严格取外，部首勹 → l。

#### 「丬」无视 qiang 声旁（P 行）

**规则**：「丬」（爿的简写）无视 qiáng 声旁，直接取为部首。

**验证**：将 jd1p。将字的声旁是爿（qiáng），但编码不把它当声旁处理，直接取丬为部首 p。
