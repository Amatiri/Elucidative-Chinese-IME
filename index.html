Philosophy

编码，应当解释汉字，
而不是遮蔽汉字。

解书音形的编码充分考虑字源字义，又以现代字型为准。它保持文化敏感： 编码反映汉字的结构演变和文化内涵，动态分配，注释避重。

“知音辨形，
高效输入。”
—— 解书音形设计理念

常用优先

最常用的汉字获得最短的编码。输入频率决定码长分配，让高频操作尽可能轻快。

零重码

每个编码都有唯一汉字。取消候选翻页的干扰，让“想到即打出”成为可能。

渐进学习

初期只记音码与主码基础，中期在实战中熟悉副码，高级再掌握全规则。规则为效率服务，而非相反。

Structure

ABCD(E)(.F)

每个汉字的完整编码由音码、主码、副码与补码构成。 前三码必填，后两码可选——编码长度随复杂度自然伸缩。

A B C
音码 · 必填
搜狗双拼 + 声调，0 轻声。忠实记录真实、准确的发音。
D
主码 · 必填
部首 / 独体区分形码。独体字按数字编码，合体字按部首字母编码。
E
副码 · 可选
余字 / 查重注释形码。同音同主码时用于区分，多数常用字无需副码。
.F
补码 · 可选
繁异 / 同义补充。日常输入很少用到，为特殊场景保留。
码表排序 前缀匹配 自动上字 自动拆分 优先上词

五大机制协同，在“唯一确定”的前提下，让编码尽可能短。

Interface & Settings

看得见的候选，
看不见的规矩。

前端默认以「内输」方式运行，只在输入法程序预设的框内输入； 同时按下 ← 与 → 可切换到「外输」，在任意全局输入框中输入，未输入编码时仅显示命令行后台。 按 Esc + 1 可取消内外输切换，进入“仅内输”。

以「ime.py」为准：

外观与设置

  • 顶部输入框：实时显示输入内容，支持文本编辑。
  • 三个显示标签：词语候选与多字词首选组合、当前单字候选列表、状态提示（如「字 1/2 页 1」，一般隐藏）。
  • 底部状态栏：设置选项与字典条目数统计。
  • 自动上字：输入编码超过 3 位且候选唯一时，自动上屏。
  • 优先上词：词语候选排在首选字之前，空格优先上屏词语。
  • 形部表：显示笔画 / 构形 / 部首编码参考表，窗口高度自动调整。
  • 外输精简：去掉标题栏与设置区，仅保留输入框和一行候选预览。

输入功能

  • 单字输入：Shift+1~5 选择第 1–5 个候选，空格 选第一个，↑ / ↓ 翻页。
  • 自动拆分：系统自动将长编码拆分为多个字码，也可输入 ' 单引号显式分隔。
  • 切换选字：= 切到下一个字，- 切到上一个字。
  • 上屏：空格 上屏所有首选字（或词语），Shift+1 / Shift+2 按顺序上屏。
  • 剪贴板同步：输入内容自动复制到剪贴板。
  • 外输 Enter：保留原来的编码上屏，不替代为相应汉字。
  • 简打要点：单字简码注意前切与后切，避免被自动拆分或自动上字“吃掉”。

Learning Path

先用，再学。

解书音形适合追求认知效率、又不愿死记硬背的用户。 不必等规则背完才开始——从第一次敲键起，路径会自己展开。

初期 音码 + 主码基础

掌握双拼音码，再了解主码的数字编码与关键部首。只记前四码，就能覆盖大部分日常输入。

中期 副码与重码区分

在常用字实战中逐步熟悉副码规则。遇到同音同主码的字，自然记住区分方式，而非集中背诵。

高级 全规则与特例

补码、未简字副码、余单笔画特殊编码——这些规则在需要时查阅即可，不必成为入门的负担。

Tools & Resources

码表之外，
还有一整套工具。

main.py 提供批量录入、添加单字、编辑修改、分析音区、整理码表、添加理据、查询字码、添加词语、猜测编码等管理功能。 部分能力已 CLI 化，运行 python main.py -h 查看。

批量录入

输入一串汉字，自动生成音码，为每个读音指定形码，自动处理重码冲突。

整理码表

自动去重排序，一级简码优先，生成网页码表与理据数据。新克隆仓库建议先跑一次。

添加理据

为合体字补充手工理据，支持按序、随机、指定汉字三种模式，自动保存。

查询字码

输入汉字，显示已有编码，多个读音斜杠分隔，同时输出未编码汉字串。

添加词语

两字词自动生成组合编码，多字词支持默认或手动序列，可保存多个编码变体。

猜测编码

随机抽字，猜主码 / 猜副码，猜对后显示完整编码，以游戏方式巩固记忆。
