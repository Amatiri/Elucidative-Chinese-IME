# 解书音形 · 移动端 Demo v0.3

桌面端 `ime.py` 外输模式的浏览器移植。目标是把
**编码引擎 + 键盘交互 + 显示分区**三件事在手机上跑通，作为后续鸿蒙 / Android
原生输入法的可执行规格。

- 引擎：TypeScript，纯函数、零运行时依赖、零 DOM / IO
- UI：原生 DOM + Pointer Events，不引入框架
- 形态：PWA，可装到手机主屏离线使用
- 布局：5 行（方案 H，默认）与 6 行变体（设置里可选），一套代码一个 flag 切换

---

## 快速开始

```bash
cd mobile

npm install          # 只装 typescript（devDependency）
npm run build        # tsc -p tsconfig.web.json → web/assets/
npm run build:golden # golden 夹具不入库，首次 / 码表变更后重生成（需 Python）
npm test             # 引擎单元测试（54 项）
npm run serve        # python -m http.server 8080 -d web
```

浏览器打开 `http://127.0.0.1:8080/`。

> `npm run serve` 依赖 PATH 上的 `python`。没有的话换任意静态服务器，
> web 根目录指向 `web/` 即可。

逻辑级校验（不依赖浏览器，吃构建产物，改键位后必跑）：

```bash
node tools/validate_layout.mjs
# VALIDATION_OK / rows=6, totalKeys=46, radicalGroups=26
```

检查每行 span 之和、Row6 键面与列宽比、`KEY_BY_MAIN` 唯一性、部首表 26 组、
⌫ 的「清」副字符与 `clearAll` 上滑、部首浮层与切布局不动编码状态。

**改完代码看不到变化？** Service Worker 会缓存旧资源。升 `web/sw.js` 里的
`CACHE` 版本号，或在 DevTools → Application → Storage 里 Clear site data。

## 引擎门面

UI 层只 `import { createEngine }`，不碰内部模块：

| 方法                                         | 用途                     |
| ------------------------------------------ | ---------------------- |
| `queryByPrefix(prefix, startIdx?, count?)` | 结构化候选（含 `rest` 剩余编码）   |
| `splitSequence(s)`                         | 自动分词，用 `'` 分隔部件        |
| `getPhraseSegments(code)`                  | `(预览, 部件列表, 字面部件下标)`   |
| `queryMultiChars(splitText)`               | 各段首选字拼串（任一段无候选则整串空）    |
| `queryPhrase(code)`                        | 编码 → 词语（含括号）           |
| `processInput(text)`                       | 从输入流提取合法编码串            |
| `nextCharClass(prefix)`                    | 下一键分档，覆盖 CODE_CHARS 全集 |

**顺序即语义**：候选顺序 = `dictionary.txt` 行序，引擎内任何地方都不得排序。

## 键盘布局

### 5 行（方案 H · 10 列，默认）

| 行    | 内容                         |
| ---- | -------------------------- |
| Row1 | 小显示区(1) · 候选区(8) · ∨ 翻页(1) |
| Row2 | `1 2 3 4 5 6 7 8 9 0`      |
| Row3 | `Q W E R T Y U I O P`      |
| Row4 | `A S D F G H J K L ;`      |
| Row5 | `' Z X C V B N M = ⌫`      |

Row4 / Row5 的功能键（副字符）：

`A`自动上字 · `S`优先上词 · `D`翻译 · `F`剪贴板 · `G`\< / 左移 · `H`\> / 右移
`'`大小写 · `Z`部件表 · `C`设置 · `=`下一个字

以下五键的副字符在 **6 行布局下隐藏**（功能已提升为 Row6 主键），5 行完整保留：

`X`🌐语言 · `V`英文逗号 , · `B`空格 · `N`英文句号 . · `M`回车

### 6 行变体（设置里可选）

在 Row5 下追加一行，列宽比 `🌐 1U / , 1U / 空格 5U / . 1U / ↵ 2U = 10U`：

```
Row6: [🌐] [,] [     空格     ] [.] [ ↵ ]
```

- `,`：输出**英文逗号**；编码态走「放弃输入再出符号」语义（对齐 `ime.py:777-780`）
- `.`：双身份 —— 编码态作**补码引导符**进编码流，空闲态直出英文句点。
  6 行下它是补码引导符的唯一入口（N 上滑已改为输入 `n`）
- `空格`：编码态上屏首选，空闲态输出空格（与上滑 B 同源）
- `↵`：编码态放弃输入，空闲态回车（与上滑 M 同源）
- `🌐`：语言切换，P2 待实现（toast 占位）
- 6 行下：`V` 上滑的逗号摘除，`N` 空闲态句点下沉到 Row6；`X/V/B/N/M` 副字符隐藏
- 大写（`'`）、部件表（`Z`）、设置（`C`）、减号（`=`）在两种布局下**都保留且位置不变**

## 交互

| 手势            | 行为                              |
| ------------- | ------------------------------- |
| 点按            | 输入编码字符 / 触发主键功能                 |
| 上滑            | 取副字符（阈值 15px）；**无可见副字符 → 视作单点** |
| 左滑 / 右滑       | 仅 `G` 左移 / `H` 右移光标；其余键**视作单点** |
| 长按 `⌫` ≥600ms | 加速连删（50ms/次，删完自动停，松手不多删）        |
| 上滑 `⌫`        | 清空已上屏文本（3s 内再滑一次确认）             |

**手势不吞键**：任何方向的手势要么产出副字符语义，要么退回单点，不存在「滑了没反应」。

### 副字符随状态切换（`subTextOf`）

键面副字符的实际显示内容由 `keymap.ts` 的 `subTextOf(def, coding, rows)` 统一决定，
**渲染与手势门控共用这一个函数**，两处不允许各自漂移：

- 6 行下 `X/V/B/N/M`（`hideSubIn6Row`）副字符为空 → 上滑视作单点
  （6 行下上滑 `B` 输入 `b` 进编码流，不再出空格）
- `⌫` 带副字符「清」→ 上滑走清空，不会退化成单点退格
- 编码态下受设置项约束的符号键副字符灰显（`subDim`），行为由「上滑输入符号」决定

### `⌫` 三态

| 操作         | 行为                                                 |
| ---------- | -------------------------------------------------- |
| 点按         | 退格：先删编码，编码为空才删光标前的已上屏字符                            |
| 长按 ≥600ms  | 加速连删：立即删一次，随后 50ms/次；文本与编码都空时自动停表                  |
| 上滑（一次）     | 置 3s 确认窗口 + toast「再滑一次 ⌫ 清空全部」                     |
| 上滑（窗口内第二次） | 清空**已上屏文本**（`committed` + 光标归零），**编码 `buffer` 保留** |

长按计时期间位移超过 15px 即取消（判为滑动）；确认窗口内按了别的键则作废。
长按其余键（如 `Q`）不消费长按，松手照常输入 —— 长按不吞键。

### 空闲态直出

`ime.py:721`：数字 / `;` / `.` / `'` 只在「已有编码字符」时才进缓冲，
空闲态直接外输。

但 **26 个字母一律进缓冲**，不看分档结果 —— 真值表第 0 位里 `a`、`e`
归入 `multiOnly`，含义是「不能作**单字**编码的开头」，不等于不能输入：
它们仍可能是**词语编码的类型符**。按 empty 直出会把 `a`、`e` 挡在输入流之外。

### 大小写三态

上滑 `'` 循环：**小**（lower）→ **大**（once）→ **连**（upper）。

- 大 / 连 下字母**直接上屏大写**，不进编码缓冲
- 大 用完一次自动回落小；连 保持不变

### 逐字选择

多字态下 `=`（单击）进入并跳到下一个字，`-`（上滑）回到上一个字。
选完一个部件自动推进到下一个未选部件，全部选完则整串上屏。
**字面部件**（无候选、按编码原样输出）会被自动跳过。

选中一个字后，`ime.py:424-441` 会把**剩余编码补回输入框**：

```
ceu → 单击 = 进字 1/2 → 上滑 4 选「测」（rest = "4u"）→ 编码串由 ceu 变为 ce4u'u
```

于是上方下划线的编码实时补全，后续翻页与再选字都基于补全后的完整编码
（此时 `parts` 从 `["ce","u"]` 变成 `["ce4u","u"]`，预览串为「测是」）。
同时左上角小显示区显示刚选中的「测」—— 手机上手指挡住候选条，选完需要确认。

退格的行为由设置项决定：默认删掉一位编码字符**并**退出逐字选择
（桌面端 ime.py:752-758 无条件删字符，退出只是输入变化后状态重置的连带效果）。

### 部件表浮层（上滑 `Z`）

对齐 `ime.py:984-1011` 的 `radical_table_data`，**26 组**（25 个声母字母 a–z 去 e + `0-9`）。
首组标签移动端为「**笔画**」（桌面端 `a(副)`），仅显示标签不同，部首串未动。

- 覆盖原键盘、与键盘等高，右上角 `×` 关闭
- 开 / 关只切 `radicalOpen` 一个布尔位，**不触碰编码 / 候选 / 逐字选择状态**，
  关闭后原键盘原样保留
- 数据只读，不重排、不补全

## 显示分区

对齐 `ime.py` 的 `update_display()`：

| 区域       | 内容                                                   |
| -------- | ---------------------------------------------------- |
| 目标输入框（上） | 已上屏文本 + 正在输入的编码（下划线）+ 光标；**可长按选中复制**                 |
| 左上小显示区   | 最后按下的那个键；空闲态显示大小写档位「小/大/连」                           |
| 中间候选区    | 单字态 → 5 条候选（汉字 + 剩余编码）；**多字态 → 不出单字候选**，改出多字预览串 + 词语 |

多字态的预览串与词语**等大、靠左、可分别点击上屏**。靠左是为了避免词语
出现 / 消失时整串位移。

### 键帽视觉档位

`KeyClass` 四态：`normal`（常态）/ `dim`（下一键无候选，仍可点只灰显）/
`func`（无编码字符的功能键）/ `subDim`（编码态下副字符灰显）。

没有 `recommended` 档：引擎只有 `content / empty` 两档数据，
`content` 键保持常态即「可按键」，第三档无数据来源。**没有「禁用」视觉**——
空码区是规则 §六 的可用扩展面，画成不可点会砍掉这个特性。

### 多字预览的两条分支（`ime.py:527-534`）

```
手动单引号 + 优先上词 → 增强预览：预览串 = getPhraseSegments().display，不再单列词语
其余情况             → 预览串 = queryMultiChars()，词语单独成项「厕是   (测试)」
```

增强路径的价值在于**字面段按编码原样输出**：

| 输入       | 增强路径 | 普通路径  |
| -------- | ---- | ----- |
| `b;'qil` | 兵起来  | 兵七了   |
| `ni';hk` | 你;hk | **空** |

`queryMultiChars` 只要任一段无候选就整体返回空串，`getPhraseSegments` 不会。

**普通路径下的兜底**：`queryMultiChars` 返回空（即编码不对应任何候选，如英文词
`deepseek` → `de'ep'se'ek`，`ep`/`ek` 无候选）时，预览基准串回退到
`seg.display` —— 它把整串按**字面**回显。于是空格 / 上屏首选上屏的正是
用户输入的原始编码（`deepseek` → 上屏 `deepseek`），而不是静默无反应。

## 设置项（上滑 C 打开，仅空闲态）

| 项              | 默认    | 说明                                            |
| -------------- | ----- | --------------------------------------------- |
| 上滑输入符号         | 放弃输入  | 放弃输入保留原编码（`ime.py:777-780`）；「禁用」是移动端独有的一档     |
| 逐字选择下按退格删除一位字符 | **开** | 关＝只退出逐字选择、编码保留；开＝删一位**并**退出（`ime.py:752-758`） |

> 改默认值时必须同时换 `settings.ts` 里的 localStorage key，
> 否则老用户读到的仍是旧默认值。

### 单字 / 多字的判定（`ime.py:501`）

看的是**分词结果里有没有单引号**，不是过滤空段后的段数。

`splitSequence("wj4u'") === "wj4u'"`，按 `'` 切再滤掉空段只剩 1 段 ——
按段数判会误判成单字，于是自动上字把 𬇕 顶上屏。而人工单引号意味着用户
在做多字输入，ime.py 走多字分支，不会自动上字。
