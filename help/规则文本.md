# 解书音形编码规则

## 前言

解书音形是一种**音形结合、零重码、可自定义**的现代汉字输入方案,采用ABCD(E)(.F)的编码结构,兼顾**易学性**和**高效率**。本输入法秉承"**知音辨形,高效输入**"的理念,让用户在掌握拼音的基础上,通过少量形码规则即可实现高速盲打。解书音形的编码是一个充分考虑字源字义,又以现代字型为准的编码方案,保持文化敏感:编码反映汉字的结构演变和文化内涵,以音切入,以义定形,动态分配,注释避重。

## 一、编码结构概览

每个汉字的完整编码由以下部分组成:

```
ABCD(E)(.F)
```

其中:

- **ABC(音码)**:基础音码,忠实记录真实、准确的发音(必填)
- **DEF(形码)**:书写描述。有一个重要的原则:在规范、直觉、效率之间做平衡
  - **D**:主码:部首/独体区分形码(必填)
  - **E**:副码:余字/查重注释形码(可选)
  - **F**:补码:繁异/同义补充形码(可选)

### 核心要点:

**核心思想**

**常用优先**:最常用字编码最短 **零重码**:每个编码都有唯一汉字

**音码:** 搜狗双拼+声调,0轻声。

**主码:**

1. **独体数字编码(按优先级)** 3开形(八) > 6大形(大) > 0闭形(口) > 5称形(中) > 1竖形(丨)
   = 2横形(一) > 4错形(㐅) > 7偏形(厂) > 9复形(复) > 8奇形(乙)

2. **合体字母编码(部首→部首码)**
   
   **关键部首码**:
   
   - j=金,k=口,m=木,r=人,s=丝,t=土,u=水,x=心,y=言
   
   - 完整部首表作为参考

**副码:**

1. **何时需要副码?**
   
   同音码+同主码(前四码都相同)的若干合体字,除最常用字,其余字都需副码。

2. **副码选择顺序** 空 > 部首别码 > 余字解析码 > e > ; > 其他字母

3. **核心方法** 部件在部首表内取部首码,表外取初码

**补码与特殊规则**

1. **补码格式:.X**
   
   - 主要用于繁体字、异体字
   - 日常输入很少用到

2. **特殊规则摘要**
   
   - 独体字没有副码
   - 未简字副码(若有)优先为;
   - 余单笔画有特殊编码

**设计理念总结**

1. **三层结构** 音码(ABC) → 形部(D) → 补充(E/F)
   
   - 知道读音就能输入
   - 记少量形码就能精确

2. **渐进学习**
   
   - 初期:掌握音码,再掌握主码基础,只记前四码
   - 中期:常用字实战练习,再逐步学习副码,区分重码
   - 高级:掌握全规则

3. **实用主义**
   
   - 规则为效率服务
   - 相似字编码模式一致

**学习建议**:**先用再学**、**实战为主**、**善用工具**。

这套输入法适合追求认知效率又不愿死记硬背的用户。该规则是对既有编码状况的解释性归纳描述,作用是帮助理解编码的内在逻辑和常见模式,而非机械地规定每个汉字必须如何编码。当与实际编码不一致时,以实际编码为准,并作为优化分配特例。

## 二、音码编码规则

**转换原则**:将全拼(不含声调)拆分为声母和韵母,分别映射到双拼字母,然后附加声调数字。整个过程是**机械的、一一对应的**,不引入额外变化。(严格使用搜狗双拼)

**初码(A)声母:** zh,ch,sh→v,i,u。

零声母:a,o,e→o。全拼中不存在以i,u,ü开头的拼音,分别视为声母y,w,y。

其他声母同全拼。

**韵码(B)韵母:**

a,e,i,o,u同全拼。

iu→q,ua/ia→w,uan/üan/er→r,üe→t,uai/ü→y(声母jqxy的,ü→u),uo→o,un/ün→p,ong/iong→s,uang/iang→d,en→f,eng→g,ang→h,an→j,ao→k,ai→l,ei→z,ie→x,iao→c,ui→v,ou→b,in→n,ian→m,ing→;

**调码(C)声调:**

用数字标记:0为轻声,1为阴平,2为阳平,3为上声,4为去声。

hng→hn,hm→hm,ng→nv,n→on,m→mv。

## 三、主码编码规则

主码是编码中的第四位,用于区分同音字。它将汉字分为**独体字**和**合体字**两大类,并赋予不同的编码规则。因此,主码又称"形部码"。

### 1. 合体字判定标准

一个汉字是否属于合体字,按照以下标准判断:

- **可拆分性**:能够拆出**非单笔画部首**的字,视为合体字;否则为独体字。"拆"要求独立明显,不交错、不穿插、不粘连。取完部首后,剩下的部件应尽量成字,避免拆分出无意义的部件。
- **现代字形原则**:所有字源不清的字(包括错释、模棱两可、关系复杂、隶变等),统一按现代字形处理。※对于独体合体分辨不清的,也要优化分配(3.3)。
- **解书拆分法**:为了实现精确拆分,我们采用"解书"拆字法。

### 2. 独体字的分类与优先级(独体构形)

独体字根据其字形特征分为以下10类(主码为数字),并按照优先级从高到低排列:

| 类别  | 主码  | 特征说明                                 | 例字    |
| --- | --- | ------------------------------------ | ----- |
| 开形  | 3   | 笔画相互分开                               | 二三六八火 |
| 大形  | 6   | 横、撇、捺构成汉字主要框架                        | 矢水米乘求 |
| 闭形  | 0   | 有占据主导地位的封闭部件                         | 自酉曲凸甘 |
| 称形  | 5   | 可构成上下或左右对称                           | 中且臣丞丽 |
| 竖形  | 1   | 字形瘦高,或有贯穿汉字的竖画                       | 生主已幺毛 |
| 横形  | 2   | 字形矮宽,或有贯穿汉字的横画                       | 人之而瓜也 |
| 错形  | 4   | 有占主导的交错粘连的笔画                         | 刀舟正不壬 |
| 偏形  | 7   | 汉字重心不稳,左下角或右下角空缺                     | 产勿今母耳 |
| 复形  | 9   | 结构复杂,包含多个符合上述形状的结构;或隶变后无法辨认拆形而导致的独体字 | 南先弗巳重 |
| 奇形  | 8   | 以上字形都不符合,或以上字形都被更常用的字占用所产生的重码独体字字形   | 乙乂丩厶  |

**注意**:

- 优先级表示当某个汉字符合多个类别时,按优先级高的类别编码。横形与竖形实际上是同级互斥。
- 对于独体字的衍生,只有当衍生出的新字并未构成任何新构形时,才采用原构形;否则均认为原构形被打破,使用新构形。
- 独体字现代字形必须像独体字--这是判断复形独体字的重要标准。

### 3. 合体字的部首选取规则

合体字的主码为其**部首**的部首码,部首的选取遵循以下规则:(康熙部首+优化分配)

#### 3.1 基本原则

1. **直觉优先:** 按直觉如果能拆出一个明确无歧义的部首,则直接取该部首。
2. **康熙部首验证**:如果按直觉拆出多个部首,或按直觉难以确定部首,则根据《康熙字典》所规定的部首确定。根据常识,部首优先为形旁。汉字的部首不能取自己(即不能用整个字作为自己的部首),但是可以取部首的变体。
3. **优化分配**:若康熙部首取自己,或者在现代字形中难以辨认,或者出于避重、历史编码因素考虑,需要进行部首的优化分配(3.3)。
4. **部首表对应**:大多数部首已在部首表中给出,直接对应其部首码(见部首表),如果不在部首表中,则需要进行处理(3.4)。

#### 3.3 优化分配方法

由于"现代字形,避重,历史"三个原因,部首的优化分配诞生了以下方法:

1. **独体字/合体字判定**:确保合体字判定准确。
2. **康熙部首为本字**:按解书拆分进一步取部首。
3. **主码冲突**:当不同部首对应同一部首码(字母)时,可以调整以避免重码。
4. **亲缘衍生忽略**:若音码不同,可忽略亲缘衍生关系。
5. **特定部首规则**:部分部首有特殊规则(如外“行”取彳,含廾取廾)。
6. **现代字形与左上原则**:部首的选取需在现代汉字结构下具有区分度。如果传统部首因隶变、简化等原因在现代字形中难以辨认,或造成重码问题/与现代字形差异过大,则按解书拆分选取左/上/外部件。隶变后变得模糊难以辨认的部件,一般跳过不取。
7. **包围声旁处理**:声旁特征不明显或被外部特征覆盖时,若仅此一字如此,则取外声旁;若多字如此,则取内部件。
8. **简体问题**:有些简化字按简化前的繁体字形处理。
9. **简并/非部首字合理跳过**:若有其他部首,则不取简并部首或者未收录的成字部首。
10. **字源参考**:在无法决断时,可参考字源。

尽管方法众多,但通常情况下,《康熙字典》所规定的部首就是最优解。

### 4. 主码编码总结

- **独体字**:主码为数字(0-9),根据字形特征按优先级选取。
- **合体字**:主码为字母(b-z,不含a、e、;),对应部首表中的部首。
- **禁用**:a、e、; 不用于主码。

## 四、副码编码规则

副码是编码中的第五位,为**可选扩展码**。其主要作用是在前四码相同的一组字内实现**零重码**。副码的设计体现了"余部集合、部首传递"的核心思想。

**副码的存在规则**

- **副码省略原则**:为缩短码长,最常用字**没有副码**(即空副码)。为统一码长,需要占位时使用a作为占空码,在码表中省略不写。
- **独体字规则**:独体字的副码一律为空,依靠主码数字区分实现零重码。
- **常用度排序**:在同一前四码组内,汉字按常用度排序:
  最常用字:空副码
  次常用字:优先占用高优先级字母
  后续字:若首选字母已被占用,则顺延至下一个可用字母

**常用度判定标准**

当两个汉字常用度差别不大时,按以下优先级判定:可读性 > 含义丰富度 > 形声字声旁匹配度 > 笔画数 > 起笔。

**术语定义**

| 术语         | 定义                                        |
| ---------- | ----------------------------------------- |
| **余集合/余字** | 汉字去除主码部首后剩余的部分,如果"余集合"成字,则称"余字"。          |
| **余音**     | 余字的初码(双拼声母)                               |
| **余部**     | 余集合按"解书拆分"法进一步拆分的部件                       |
| **音似/音异**  | 余字与整字音码相似度。一般来说,余字的其中一个常用初码与整字相同为音似,否则为音异 |

### **副码选择优先级**

副码的选择遵循严格的优先级顺序:

**空副码 > 部首别码 > 余字解析码(余音/余部) > e > ; > 其余字母**

### 1. 部首别码

**条件**:余集合本身是《部首表》中的**独立部首**,且其部首码与其初码(余音)不同。则其部首码亦称为部首别码。反之若部首码与初码相同(音托),则称为无部首别码。对于有部首别码的部首,称为"别码部首",需要着重记忆。

**例外**:

1. 非部首字(如夫→矢)不在部首表中,无部首别码。
2. 部首变体(如 龶→青)视作有部首别码。

### 2. 余字解析码

当无部首别码时,按以下逻辑选择:(不成字视为难读,若余音被更高优先级的字占据,则取余部,反之同理)

| 情况           | 处理方式                                                  |
| ------------ | ----------------------------------------------------- |
| **余集合音似或难读** | 优先取余部,可采用余部首传递                                        |
| **余字音异且易读**  | 优先取余音,多个余音的,取常用余音                                     |
| **独体字作余字**   | 尝试进一步拆分(见特殊规则3),若可拆分,则进入音似性+易读性判断,取余音或余部;若不可拆分,则只有余音。 |

**递归嵌套规则**:
当余集合内部仍可拆分时,允许递归嵌套:

- "音"作为余字 → 余部"立" → "立"作为新余字 → 余部"亠",余音l
- "多"作为余字 → 余部"夕" → "夕"作为新余字 → 部首别码t,余音x

#### **余部综合规则**

**1. 余部首传递**

取余部时,如果余集合成字(合体字),则通常优先取余字的部首(参照主码取部首逻辑)作为副码来源。部首在部首表中则取部首码,不在表中则取初码。

**示例**:

- "锌":部首"钅"(金)→ 主码j,副字"辛"为合体字,部首为"立",不在部首表,取初码l。
- "锌"的副码取l("辛"的部首)

**2. 一般余集合选取**

余集合不成字时,按解书拆分顺序(左上→左下→右上→右下)依次考察各非单笔画部件。对每一部件,依次判断: 1.是否有部首别码,有→直接取为副码; 没有→2.是否易读, 难读→先跳过该部件; 易读→3.是否与整字音似, 音似→先跳过该部件; 音异→取部件常用初码。无码可取时可尝试进一步拆分,仍不可取时可逐步放开音似性和单笔画要求。

**3. 结构特殊规则**

在上下(左右)结构的字中,若满足以下条件:

1. 下(右)部为部首
2. 上(左)部为音似余字
3. 余字为上下(左右)结构,下(右)部为部首

则取**余字上(左)部**作为副码,避免"抛外取内"。

**综合示例**:

1. "音"主码分析:
   
   - "音"在康熙字典中为"音部0画"
   - 部首不能取自己,将"音"拆为"立"+"日"
   - "立"是简并部首(立→亠),"日"是表内部首
   - 根据"简并部首跳过"原则,取"日"为部首 → 主码r

2. "意"副码分析:
   
   - "意"为上下结构:上"音"下"心"
   
   - 部首为"心"(下部),余字为"音"(上部)
   
   - "音"的余部为"立"+"日",取上部"立"
   
   - "立"的初码为l
   
   - "意"的副码取l(余部"立"余音)

#### **特殊规则**

**1. 未简字处理**

在《通用规范汉字表》(8105)内,若有一个字**未进行类推简化**,缺失对应简体,称为"未简字"。

**规则**:未简字的副码(若需)优先为;(分号)

**2. 余单笔画处理**

当一个字取完部首后**仅剩单笔画**,该笔画可取为副码。

**笔画与字母对应**:"丶一丨丿乙乛𠃌乚𡿨"分别对应部首次码"dhupygkwv"。

有:系xi4sp/ji4sp。

**3** **独体字余字拆分**

以下①-③条规则为**或**关系,满足任意一条即可判定为可拆分。为了增大拆分可能性,拆分时尽量拆成非单笔画结构。

**①** **分离性可拆**:汉字可分解为两个部件,至少其中一个部件不是单笔画且属于《部首表》,两个部件之间**严格分离**(即不粘连交错穿插,点接触也不行),即可拆分。

**②** **字源性可拆**:汉字可分解为两个部件,至少其中一个部件不是单笔画(若整字属于**大形字**(主码为6),则要求所有部件均不是单笔画),且康熙部首(不是单笔画)为两个部件之一,即可拆分。

**③** **结构性可拆： "丷亠"**：汉字顶部存在"丷"或"亠"部件，且该部件未被其他笔画穿插或交错（允许外围粘连）。**"冖"**：汉字顶部存在"冖"部件，且其笔画是连续书写的，即可拆分，不受粘连/穿插/交错的限制。**"勹"/"匚"**：汉字以"勹"或"匚"作为包围外框（其他半包围外框如凵、冂等暂不适用）。**"口"**：汉字仅由两个部件组成，其中一个部件必须是"口"（不能是"日""田"等变形），另一个部件必须是成字。满足任一结构特征即可拆分。

**④ 余音被占时次选**：独体余字在前三条均不可拆分，但当余音被更高优先级字占据时：若其属于“非部首字代替”表（如干→十、兀→儿），可取代替目标的部首码作为副码；若不在“非部首字代替”表，但整字属于大形字(主码为6，即由于存在单笔画而被②筛掉的，比如“夬”)，可取“大”部首码d。余音未被占据时仍取余音。

#### **宏观验证原则**

为确保编码系统的一致性和合理性,设置以下验证原则:

**1. 对称性原则**

**字形、结构相似的字,其编码模式应尽量保持一致。**

**2. 多条件优先**

**同时满足两个条件时,优先取支持原因多的条件。**

**3. 实用主义**

在规则冲突时,以实际编码效果和用户记忆负担为最终考量。

**4. 副码优化分配**

类似主码,副码也有适当优化分配。需要理解的字例有:进zw。

## 五、简化解书拆分规则

解书拆分规则本身**不直接用于输入**，而是作为主码和副码选取的**理论依据和辅助工具**，采用一套简洁的符号系统来描述汉字结构：

| 类别    | 符号  | 含义           |
| ----- | --- | ------------ |
| 左右结构  | r.  | ⿰（左右并列）      |
| 左中右结构 | rr. | ⿲（左中右并列）     |
| 上下结构  | i.  | ⿱（上下叠加）      |
| 上中下结构 | ii. | ⿳（上中下叠加）     |
| 包围结构  | l.  | ⿸/⿹/⿺等（各种包围） |
| 交错结构  | x.  | ⿻（笔画交错，少用）   |

**部件表示法**

| 表示法      | 格式          | 说明                        | 示例               |
| -------- | ----------- | ------------------------- | ---------------- |
| 部首双码     | 部首码 + 部首次码  | 部首在部首表中的位置对应部首次码在部首次表中的位置 | 贝 → bz           |
| 独体字码     | 前四码         | 独体字的完整四码表示                | 天 → tm16         |
| **扩展字根** | **字根码（两位）** | **非部首表中的必要字符（见扩展字根表）**    | **立 → ld**       |
| 简化表示     | 见下          | 减少记忆负担的简化形式               | 贝 → bb，立 → dj/lh |

| 符号  | 含义        |

**集合语法**

| 符号  | 含义                                  |

| []  | 将相关部件分组，如 [i. sj kb 4] 表示交错上下结构“𰀉” |

**编码流程**

**步骤1：拆分**

按结构码递归拆分汉字至基础部件，直到所有部件都可用部首双码、独体字码或扩展字根表示。

**拆分原则：**

- 优先按明显结构粗拆分（左右→上下→包围）
- 包围结构统一用 `l.` 表示
- 允许编码简写（如 `fu4r` 替代重复“付”结构）

**步骤2：表示**

见上方“部件表示法”

**步骤3：组合**

按结构码组合部件序列，用空格分隔各部件。

**示例：**  
`“对”` → `r. ky cp`

- `r.`：左右结构
- `ky`：“又”的部首双码
- `cp`：“寸”的部首双码

**简化表示法（实际编码使用）**

在实际的输入法编码生成中，为简化处理，采用以下简化表示：

1. **部首双码简化：** 部首码 + `b`（作为部首提示）
2. **前四码简化：**
   - 独体字：取初码 + `d`（独体标记）
   - 合体字作部件：取初码 + `h`（合体标记）
3. **扩展字根简化：**
   - 部首简并的：用简并部首码 + `j`
   - 罕部跳过的：并入独体字表示
   - 其他扩展字根：用占位符号 `ee`
   - 可进一步拆分的扩展字根：拆分表示
4. **笔画简化：** 根据副码的单笔画对应字母 + `a`

### 核心原则

- 同一汉字可能有不同的拆分表示，允许人工调整
- 通过解书拆分识别“字义关联”的形旁部首，为合体字的主码选取提供依据
- 提供余集合拆分的部件依据，帮助确定副码的余音或余部
- 在编码冲突时提供讨论和验证的基础，帮助在多个可能编码中做出选择

## 六、补码编码规则

补码用于处理汉字在 Unicode 范围内的所有繁、异体形式，包括同义异写字、大写数字、通假古音字等，以前缀点 `.` 引导。补码一般用不到。
通常，`.` 直接表示该字在常用语境下的 **第一繁体**（如"纪"之"紀"）。
若某字仅有单一繁体且该字形有明显的地区差异，则使用地区后缀区分：

| 后缀   | 含义     |
| ---- | ------ |
| `.f` | 大陆繁体   |
| `.g` | 港澳异体   |
| `.t` | 台湾异体   |
| `.j` | 日本汉字   |
| `.u` | 通假/古音字 |
| `.k` | 韩国用字   |

若某字对应多个常用繁体（如"复"之"復"、"複"）或某个罕见繁体（"坖"），则其补码的选取规则可参照副码（如取部首别码、部首传递等）。

### 全覆盖与零重码

1.空码区类型

- **拼音缺失区**：如 `"bb"`（bou 不存在）、`"cc"` 等
- **声调缺失区**：调码 5-9（实际只有 0-4）

2.利用方案

- **预留区**：`"bb0"` 用于无拼音汉字（已在管理工具中使用）
- **编码空间疏散**：对于过挤的音区，可适当调整音码，实现暂时疏散（如 yi4 疏散到 yi8）
- **用户自定义区**：其他空码区开放给用户自由定义

ABCDE.F 形式的**解书码**覆盖 Unicode 收录的所有汉字（不包括喃字等独立文字系统），并保持全局零重码。

## 词语建议

### 一、词语编码的核心原则

**1. 基本定义**

- **广义词语**:包括多字词、常用短语、自定义短语、输入法特征词、通用符号等
- **补充功能**:外置于"多字首选字"输入的辅助方法,旨在提高输入效率

**2. 硬性规则**

- **最小长度**:词语编码至少3位,且前三位不能包含数字。
- **零重码**:一个编码仅对应一个词语(但一个词语可对应多个编码)
- **长度原则**:常用词语分配短编码,非常用词语使用长编码

### 二、多字词编码建议

**1. 二字词**

最简码(基本不用) = 第一字双拼码(即初码+韵码组合) + 第二字初码

扩展顺序:优先补充第二字的韵码(最常用) → 补充第二字调→主码

**2. 三字词**

最简码(基本不用) = 每个字初码组合

扩展顺序:补第一字韵码 → 补第二字韵码(最常用) → 补第三字韵→调→主码

**3. 四字词**

方案1(基本不用):第一字初码 + 第二字初码 + 第四字初码

方案2(常用):四个字各取初码

扩展顺序:补前三字韵码(常用) → 补第四字韵→调→主码

**4. 五字及以上**

方案1(基本不用):第一字初码 + 第二字初码 + 最后字初码

方案2(适应习惯,常用):前三字初码 + 最后字初码

扩展顺序:补所有字初码(常用) → 补最后字外的韵码 → 补最后字编码

**5.** **繁体词语**

可在简体词语末尾添加`.`补码标记表示繁体变体。

### 三、通用符号编码方案

**1. 编码结构**

类型符(1字母)+ 具体编码(至少2字母) = 3位最小码

**2. 类型符建议**

| 类型符 | 符号类型 | 示例      |
| --- | ---- | ------- |
| b   | 部首   | bdh → 亠 |
| r   | 日文假名 | rka → か |
| d   | 中文标点 | d..→。   |
| t   | 特殊符号 | tzo→"←" |
| g   | 希腊字母 | gal→α   |
| u   | 数学符号 | uqh→∑   |
| v   | 中文相关 | vr.→⿰   |

**剩余符号待更新**

**3. 具体编码规则**

- **部首**:部首双码,如"亠"→ bdh(d部首码,h为"亠"在d部首次表第4位。)
- **假名**:罗马字转写,如"か"→ rka
- **其他**:根据初码或双拼码组合转写

## 码表挂接

使用无数字版码表,便于主流输入法系统识别。无数字四位码实现如下:

首先将五个音调改为两个平仄:12→a,340→e。

前面双拼两位基本不变,除了ing适配:b,d,p,t和y的ing为d。jqx的ing为a。lmn的ing为v。

独体字:先平仄,再字形。每个平仄又分两到三声,第一声(平声中的阴平,仄声中的上声)字形字母(0-9)为pqwertyuio。第二声(平声中的阳平,仄声中的去声)字形字母为masdfghjkl。第三声(即仄声中的轻声)字形字母为zxcvbncvbn。

合体字:

先主码,再附加。附加分副码是否省略:省略副码:用平仄。副码不省略:用副码。
