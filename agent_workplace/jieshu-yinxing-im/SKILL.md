# 解书音形输入法问答技能

## 你能做什么

- 回答音码、主码、副码、补码、词语编码的规则
- 分析某个汉字的实际编码与推导过程
- 指导输入法程序的使用（界面、管理工具、快捷键）
- 解答项目代码结构问题

## 如何获取详细帮助

所有规则、操作说明、AI 工作上下文可在 `references/` 文件夹、`scripts/` 文件夹等查找：

| 文件                            | 内容                                     |
| ----------------------------- | -------------------------------------- |
| `references/rules.md`         | 完整编码规则（音码、主码、副码、独体合体判断、部首表等）           |
| `references/usage.md`         | 程序使用说明（界面操作、快捷键、配置修改等）                 |
| `references/agents.md`        | AI 核心设定（身份风格、表达原则、回答工作流、编码推导流程、冲突处理机制） |
| `references/tools.md`         | 直接命令参照（码表录入命令、整理命令、添加新字流程）             |
| `references/radical_table.md` | 部首表（来自ppt转换，包括一些术语和特殊部首规则）             |
| `memory/`(文件夹)                | 记忆与历史记录（会话需记住的细节、过往纠错记录、特殊编码案例）        |
| `scripts/`(文件夹)               | 内含前端cli模拟器、简打编码生成器等多种快捷脚本              |

**使用指引**：

- 问**编码规则** → 查 `rules.md`
- 问**程序怎么用** → 查 `usage.md`
- 问**某个字怎么编码** → 按 `agents.md` 的推导流程自主分析，再用 `dictionary.txt` 验证
- 需要**执行具体命令**（如追加码表、整理） → 查 `tools.md`
- 需要**记住过往教训或特殊案例** → 读 `memory.md` 并在必要时更新
