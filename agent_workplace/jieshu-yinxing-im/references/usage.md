# 解书音形程序使用

## 一、文件架构

**依赖库安装**：`pip install pypinyin keyboard pyperclip pywin32`。所有文件需放在同一目录下。

**项目路径**：`D:\USB\Py\输入法`

**GitHub**：`https://github.com/Amatiri/Elucidative-Chinese-IME`

**运行**：

- 输入法前端：`ime.py`
- 管理工具：`main.py`（可以运行输入法前端和整理工具，建议以管理工具为主要运行项）

**数据文件**：

- 汉字码表：`dictionary.txt`
- 无数字版码表：`dictionary_no_number.txt`
- 词语码表：`ciyu.txt`
- 功能模块包：`manager/`
- 文件路径与常量配置：`config.py`(单击安装依赖库)

## 二、外观与设置

**界面布局**

- 顶部输入框：实时显示输入内容，支持文本编辑
- 三个显示标签：
  1. 第一行：多字词首选字组合及词语候选
  2. 第二行：当前单字的详细候选列表
  3. 第三行：状态提示（如“字 1/2 页 1”，一般隐藏）
- 底部状态栏：设置选项和字典条目数统计

**设置选项**

- 点击切换开启/显示（绿），或关闭/隐藏（红）

- 自动上字：输入编码超过3位且唯一候选时自动上屏

- 优先上词：多字词输入按空格优先上屏词语

- 部首表：显示部首编码参考表，窗口高度自动调整

**外输精简**

- 去掉标题栏和设置区

- 仅保留输入框和有内容的候选/预览

## 三、输入功能

**单字输入**

1. 输入编码:输入至少1位编码

2. 显示候选:候选字显示在第二行,**显示剩余编码**

3. 选择方式:
   
   - shift+12345分别选择第1-5个候选字
   
   - 空格 选择第一个候选字上屏
   
   - ↑/↓ 翻页查看更多候选

**多字输入**

1. 自动拆分:系统自动将长编码拆分为多个字码,也可以输入"'"单引号来显式分隔。
2. 切换选字:
   - = 切换到下一个字的选择
   - - 切换到上一个字的选择
3. 上屏:
   - 按空格上屏所有首选字(若优先上词开启,则为词语)
   - 按!快速上屏词语候选(如有)

**特殊功能**

- 剪贴板同步:输入内容自动复制到剪贴板
- 内输/外输:仅在输入法程序预设的框内输入/在任意全局输入框输入,用←+→切换。外输时根据光标位置移动输入界面。为了避免快捷键冲突,可按esc+1取消内输外输切换功能,此时仅支持内输,即"仅内输"。
- 外输模式下,如果按enter键,则保留原来的编码上屏,不替代为相应汉字等字符。

**简打核心要点**

- **基本理念**：根据 码表排序+前缀匹配+自动上字+自动拆分+优先上词 五大机制协同实现唯一确定的同时编码更短。

- 单字简码注意后切，防止与后字编码意外组合导致自动上字成其他字

- 单字简码注意前切，避免自动拆分失败

- 词语编码注意前后切，可使用人工单引号分段查询

## 四、管理功能(main.py)

1. **批量录入** - 批量录入汉字
   
   - 输入一串汉字
   - 系统自动生成音码
   - 为每个读音指定形码
   - 自动处理重码冲突

2. **添加单字** - 单个添加条目
   
   - 输入单个汉字
   - 输入对应的完整编码
   - 自动检查重码

3. **编辑修改** - 编辑/删除条目
   
   - 输入要修改的旧编码
   - 输入新编码(或x删除)
   - 自动解决重码问题

4. **分析音区** - 音码码区分析
   
   - 分析特定音区的汉字分布
   - 显示独体字表和合体字表
   - 统计独体率、主码分布、副码率

5. **整理码表** - 字典整理优化
   
   - 自动去重和排序
   - 创建无数字简码版本
   - 一级简码优先排列

6. **添加理据** - 为汉字补充手工理据
   
   - 理据存储于dictionary-data.js的rationale对象。
   
   - 自动判断需理据条目：合体字无补码、或有实质补码者。
   
   - 三种添加模式：按序（从首缺开始）、随机、指定汉字（可批量）。
   
   - 交互时显示当前条目及已有理据，支持多行（\n），按a跳过，自动保存。

7. **查询字码** - 查询汉字编码
   
   - 输入一串汉字
   - 显示每个汉字的已有编码
   - 多个读音用斜杠分隔
   - 同时输出未编码汉字串

8. **添加词语** - 添加词语编码
   
   - 两字词:自动生成组合编码供选择
   - 多字词:自动生成默认编码,或者手动输入编码序列
   - 支持多个编码变体

9. **猜测编码** - 互动游戏练习汉字编码
   
   - 从字典中随机选择汉字及其完整编码
   - 猜主码:显示汉字和音码,输入主码,直到猜对或返回
   - 猜副码:显示汉字和音码,输入副码,若多次错误会提示主码作为辅助
   - 猜对后显示完整编码,帮助记忆

## 五、代码模块概览

项目主目录：`D:\USB\Py\输入法`

核心文件：

- `ime.py` ：输入法前端主程序，Tkinter GUI 界面
- `main.py` ：管理工具入口（交互菜单与 argparse 子命令双模式）
- `config.py` ：路径常量配置
- `dictionary.txt` ：汉字码表（格式：汉字 编码）
- `dictionary_no_number.txt` ：无数字版码表（格式：汉字 无数字编码）
- `ciyu.txt` ：词语码表（格式：词语 编码1 编码2...）

manager 包（`manager/`）：

- `__init__.py` ：包初始化
- `abc_analyzer.py` ：音区分析功能
- `batch_entry.py` ：批量录入功能（含拼音转换，直接调用 pypinyin）
- `ciyu_ops.py` ：词语操作功能（含词语编码生成）
- `cli_handlers.py` ：CLI 子命令处理器（main.py 各 argparse 子命令的实现，含原子写入、安全输入等工具函数）
- `dictionary.py` ：字典文件读写、查询（后端）
- `dictionary_frontend.py` ：字典文件查询、匹配（前端）
- `file_processor.py` ：文件整理、排序
- `guess_game.py` ：编码猜测游戏
- `rationale_add.py` ：理据添加（为 dictionary-data.js 补充手工理据，支持按序/随机/指定汉字三种模式）
- `single_entry.py` ：单条录入与修改

编码常量（config.py）：

- `CODE_CHARS` = "1234567890qwertyuiopasdfghjklzxcvbnm;'."
- `SELECTION_SYMBOLS` = ["!", "@", "#", "$", "%"]
- `SYMBOL_TO_INDEX` = {"!": 0, "@": 1, "#": 2, "$": 3, "%": 4}

## 六、常见问题与注意事项

1. **运行环境**：Windows + Python 3.13+，需安装 pypinyin、keyboard、pyperclip、pywin32
2. **重码问题**：如添加条目时出现重码，程序会提示并引导解决
3. **码表格式**：每行格式为"汉字 编码"，制表符或空格分隔
4. **other 文件夹**：是历史版本，不用考虑
