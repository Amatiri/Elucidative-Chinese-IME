# 解书音形程序使用

## **一、文件架构**

**依赖库安装**:`pip install pypinyin keyboard pyperclip pywin32`, `gh repo clone Amatiri/Elucidative-Chinese-IME`。所有文件需放在同一目录下。

**运行**:管理工具: main.py。输入法前端:ime.py。main.py可以运行输入法前端和整理工具,建议以管理工具为主要运行项。

**其他**:帮助文档:help/。码表:dict/。功能模块包:manager/。文件路径与常量配置:config.py(单击安装依赖库)。agent工作区:agent_workspace/(一些辅助工具)。移动端web演示:mobile/。

## 二、外观与设置

**内输/外输**:

前端默认是**外输**模式,可在任意全局输入框输入,未输入编码时仅显示命令行窗口。同时按←+→方向键切换到**内输**模式,仅在输入法程序预设的框内输入。外输时根据光标位置移动输入界面。为了避免快捷键冲突,可按esc+1取消内输外输切换功能,此时仅支持内输,即"仅内输"。

**界面布局**

- 顶部输入框:实时显示输入内容,支持文本编辑
- 三个显示标签:
  1. 第一行:多字词首选字组合及词语候选
  2. 第二行:当前单字的详细候选列表
  3. 第三行:状态提示(如"字 1/2 页 1",一般隐藏)
- 底部状态栏:设置选项和字典条目数统计

**设置选项**

- 点击切换开启/显示(绿),或关闭/隐藏(红)

- 自动上字:输入编码超过3位且唯一候选时自动上屏

- 优先上词:多字词输入按空格优先上屏词语

- 形部表:显示笔画/构形/部首编码参考表,窗口高度自动调整

**外输精简**

- 去掉标题栏和设置区
- 仅保留输入框和一行候选/预览 

## 三、输入功能

**单字输入**

1. 显示候选:候选字**显示剩余编码**

2. 选择方式:
   
   - shift+12345分别选择第1-5个候选字
   
   - 空格 选择第一个候选字上屏
   
   - ↑/↓ 翻页查看更多候选

**多字输入**

1. 自动拆分:系统自动将长编码拆分为多个字码,也可以输入「'」单引号来显式分隔。
2. 切换选字:
   - = 切换到下一个字的选择
   - \- 切换到上一个字的选择
3. 上屏:
   - 按空格上屏所有首选字(若优先上词开启,则为词语)
   - 按!快速上屏词语候选(如有)

**特殊功能**

- 剪贴板同步:输入内容自动复制到剪贴板
- 外输模式下,如果按enter键,则保留原来的编码上屏,不替代为相应汉字等字符。

**简打核心要点**

- **基本理念**：根据 码表排序+前缀匹配+自动上字+自动拆分+优先上词 五大机制协同实现唯一确定的同时编码更短。

- 单字简码注意后切，防止与后字编码意外组合导致自动上字成其他字

- 单字简码注意前切，避免自动拆分失败或匹配其他词语

- 词语编码要前后切，可使用人工单引号分段查询

手机前端模拟：[解书音形 · Demo](https://frontend-mobile.netlify.app/)

## 四、管理功能(main.py)

1. **批量录入** - 批量录入汉字
   
   - 输入一串汉字
   - 系统自动生成音码
   - 为每个读音指定形码
   - 自动处理重码冲突

2. **添加单字** - 单个添加条目
   
   - 输入单个汉字
   - 输入对应的完整编码
   - 自动检查重码

3. **编辑修改** - 编辑/删除条目
   
   - 输入要修改的旧编码
   - 输入新编码(或x删除)
   - 自动解决重码问题

4. **分析音区** - 音码码区分析
   
   - 分析特定音区的汉字分布
   - 显示独体字表和合体字表
   - 统计独体率、主码分布、副码率

5. **整理码表** - 字典整理优化
   
   - 自动去重和排序
   - 创建无数字简码版本
   - 一级简码优先排列

6. **添加理据** - 为汉字补充手工理据
   
   - 理据存储于dictionary-data.js的rationale对象。
   - 自动判断需理据条目：合体字无补码、或有实质补码者。
   - 三种添加模式：按序（从首缺开始）、随机、指定汉字（可批量）。
   - 交互时显示当前条目及已有理据，支持多行（\n），按a跳过，自动保存。

7. **查询字码** - 查询汉字编码
   
   - 输入一串汉字
   - 显示每个汉字的已有编码
   - 多个读音用斜杠分隔
   - 同时输出未编码汉字串

8. **添加词语** - 添加词语编码
   
   - 两字词:自动生成组合编码供选择
   - 多字词:自动生成默认编码,或者手动输入编码序列
   - 支持多个编码变体

9. **猜测编码** - 互动游戏练习汉字编码
   
   - 从字典中随机选择汉字及其完整编码
   - 猜主码:显示汉字和音码,输入主码,直到猜对或返回
   - 猜副码:显示汉字和音码,输入副码,若多次错误会提示主码作为辅助
   - 猜对后显示完整编码,帮助记忆

10. **码表路径** - 指定三个码表的存储路径
    
    - 单字码表、单字无数字码表、词语码表
    - .txt结尾，若不存在可自动创建空码表
    - 最终自动检查依赖库，需要重启生效

11. **强启前端** - 阻滞性启动输入法前端

12. **其他工具** – 浏览、选择并运行agent_workspace/中的工具脚本。

注：部分功能已经实现cli化，详情`python main.py -h`。

# 解书音形编码规则

## 前言

解书音形是一种**音形结合、零重码、可自定义**的现代汉字输入方案,采用ABCD(E)(.F)的编码结构,兼顾**易学性**和**高效率**。本输入法秉承"**知音辨形,高效输入**"的理念,让用户在掌握拼音的基础上,通过少量形码规则即可实现高速盲打。解书音形的编码是一个充分考虑字源字义,又以现代字型为准的编码方案,保持文化敏感:编码反映汉字的结构演变和文化内涵,以音切入,以义定形,动态分配,注释避重。

## 一、编码结构概览

每个汉字的完整编码由以下部分组成:

```
ABCD(E)(.F)
```

其中:

- **ABC(音码)**:基础音码,忠实记录真实、准确的发音(必填)
- **DEF(形码)**:书写描述。有一个重要的原则:在规范、直觉、效率之间做平衡
  - **D**:主码:部首/独体区分形码(必填)
  - **E**:副码:余字/查重注释形码(可选)
  - **F**:补码:繁异/同义补充形码(可选)

### 核心要点:

**核心思想**

**常用优先**:最常用字编码最短
**零重码**:每个编码都有唯一汉字

**音码:** 搜狗双拼+声调,0轻声。

**主码:**

1. **独体数字编码(按优先级)**
   3开形(八) > 6大形(大) > 0闭形(口) > 5称形(中) > 1竖形(丨)
   = 2横形(一) > 4错形(㐅) > 7偏形(厂) > 9复形(复) > 8奇形(乙)

2. **合体字母编码(部首→部首码)**
   
   **关键部首码**:
   
   - j=金,k=口,m=木,r=人,s=丝,t=土,u=水,x=心,y=言
   
   - 完整部首表作为参考

**副码:**

1. **何时需要副码?**
   
   同音码+同主码(前四码都相同)的若干合体字,除最常用字,其余字都需副码。

2. **副码选择顺序**
   空 > 部首别码 > 余字解析码 > e > ; > 其他字母

3. **核心方法**
   部件在部首表内取部首码,表外取初码

**补码与特殊规则**

1. **补码格式:.X**
   
   - 主要用于繁体字、异体字
   - 日常输入很少用到

2. **特殊规则摘要**
   
   - 独体字没有副码
   - 未简字副码(若有)优先为;
   - 余单笔画有特殊编码

查询汉字: [解书音形 · 编码查询](https://iaxp.netlify.app/)

**设计理念总结**

1. **三层结构**
   音码(ABC) → 形部(D) → 补充(E/F)
   
   - 知道读音就能输入
   - 记少量形码就能精确

2. **渐进学习**
   
   - 初期:掌握音码,再掌握主码基础,只记前四码
   - 中期:常用字实战练习,再逐步学习副码,区分重码
   - 高级:掌握全规则

3. **实用主义**
   
   - 规则为效率服务
   - 相似字编码模式一致

**学习建议**:**先用再学**、**实战为主**、**善用工具**。

这套输入法适合追求认知效率又不愿死记硬背的用户。该规则是对既有编码状况的解释性归纳描述,作用是帮助理解编码的内在逻辑和常见模式,而非机械地规定每个汉字必须如何编码。当与实际编码不一致时,以实际编码为准,并作为优化分配特例。
